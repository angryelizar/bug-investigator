# 09 — Investigation укладывается в лимит Groq

Status: ready-for-agent
Blocked by: 03

На бесплатном тарифе Groq (`openai/gpt-oss-120b`, 8 000 TPM) Analyst не доходит до Verdict. На OpenAI проблемы нет; Groq нужен для разработки (спецификация, «Модели и наблюдаемость»).

## Готово, когда

- [ ] «версия java старая» на Groq при красном Baseline (`main` = `bugset-1`) даёт `insufficient_data`, а не «агент сдался»
- [ ] Текст issue #2 (hourlyRate) на Groq при том же Baseline даёт `blocked`
- [ ] На OpenAI поведение и расход не меняются

## Что известно

**2026-11-22 — из прогонов 03.**

1. **413, запрос больше лимита.** Переписка ReAct растёт с каждым результатом инструмента (до `max_output_chars` = 6 000 символов ≈ 2 000 токенов), через 4–5 вызовов один запрос Analyst — 8 230 токенов. 413 не повторяется SDK, финал — «агент сдался». Слать в модель всю переписку может и итоговый запрос этапа (`_final_answer`), не только шаги ReAct.
2. **Проба: урезание переписки** (откачено, не в коде). Чистая функция `fit(messages, max_tokens)`: старые `ToolMessage` заменяются заглушкой «результат read_file(…) скрыт — вызови снова», сообщения не удаляются (провайдеры требуют ответ на каждый `tool_call_id`), последние 2 результата не трогаются; оценка — символы / 3. Подключение — `pre_model_hook` у `create_react_agent` (`{"llm_input_messages": …}`, состояние агента полное) и перед `structured.invoke` в `_final_answer`; бюджет `BI_MAX_PROMPT_TOKENS` (≈6 000 для Groq, не задан — без урезания), за вычетом системного промпта и схем инструментов. Итог: 413 ушёл, но Analyst упёрся в 15 вызовов инструментов.
3. **Почему 15 вызовов** (трейс вызовов инструментов): при бюджете 6 000 и результатах по 6 000 символов в запрос помещаются ~2 результата, модель перечитывает скрытые файлы (вызовы 5–6 повторяют 2–3). Кроме того, на «версия java старая» модель разбирает упавший тест Baseline, хотя симптома в Bug Report нет.

## Варианты, которые стоит проверить

- `BI_MAX_OUTPUT_CHARS≈3000` для Groq вместе с урезанием — больше результатов в бюджете, меньше перечитываний.
- В промпт Analyst: сначала решить по тексту, есть ли симптом; без симптома — сразу `insufficient_data`, без инструментов и без разбора Baseline. Сэкономит заход и на OpenAI.
- Если урезания мало — другая модель Groq или Groq только для коротких этапов; решение записать в ADR.
- `create_react_agent` помечен устаревшим (LangGraph V1 → `langchain.agents.create_agent` с middleware) — урезание может лечь в middleware, если будем мигрировать.

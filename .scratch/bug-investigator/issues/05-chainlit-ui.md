## Comments

**2026-11-23 — реализация.**

- Запуск: `uv run chainlit run src/bug_investigator/ui.py`.
- `investigation.py` — Investigation по паузам без Chainlit: `run(on_event, answer)` гонит граф до следующей паузы (`stream_mode=["tasks", "updates"]`: старт узла → `NodeStarted`, итог → `NodeFinished`), `stop()` обрывает на границе узла, `abandon()` удаляет рабочую копию, если `cleanup` графа не дошёл. CLI переведён на него; тексты статусов узлов вынесены в `progress.py` и общие для CLI и UI.
- UI: сообщение, состоящее только из ссылки на issue, читает issue (только из Target Repository), иначе текст — Bug Report. Шаг на каждый узел: пока узел идёт — «Analyst ищет проблемное место…», по завершении — статус как в CLI. Граф идёт в рабочем потоке, шаги шлются через `cl.run_sync` с родителем текущего run-шага (иначе встают после сообщений).
- Пауза: сообщение с содержимым (Plan / объяснение + Reproduced/Unreproduced + сборка + Critic + diff / обоснование «Не баг»), затем кнопки; «Доработать» спрашивает комментарий следующим сообщением (пустой — переспрашивает). Нет ответа сутки — «Отклонить».
- Stop и закрытие чата: граф обрывается на следующем узле и удаляет рабочую копию; на паузе она удаляется сразу.
- Тестов нет (решено: переходы пауз покрыты `test_graph.py`, UI проверен вручную). Проверено в браузере на графе с `FakeStages`: шаги по порядку, «Доработать» с комментарием, петля Critic, Fix Approval с diff, итог со ссылкой на Fix PR, отказ для issue из чужого репозитория. CLI с `FakeStages` — без изменений в выводе. Прогон с настоящей моделью через UI ещё не делался.

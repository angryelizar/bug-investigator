## Comments

**2026-11-22 — реализация.**

- Граф компилируется с `InMemorySaver`; паузы — `interrupt` в узлах `not_a_bug_approval`, `plan_approval`, `fix_approval`, ответ — `Command(resume={"decision": "approve"|"reject"|"revise", "comment": …})` на том же `thread_id`. Ответ хранится в state (`*_approval`).
- «Доработать»: «Не баг» → Analyst, Plan → Planner, Fix → Planner; комментарий человека попадает в задачу этапа. Доработка человеком сбрасывает счётчик попыток петли Critic; после доработки Fix замечания принявшего его Critic Planner не видит как отказ.
- «Отклонить» — outcome `rejected`, без комментария в issue (в том числе для «Не баг»).
- Каждый Plan, в том числе из петли Critic, проходит Plan Approval: код меняется только по одобренному Plan.
- Вход по issue: `--issue <ссылка>` в CLI, `GitHub.bug_report` — заголовок и текст, только из Target Repository, PR отклоняется.
- Публикация: коммит (автор из git config, иначе «Bug Investigator»), push `bug-investigator/<N|хэш>` с суффиксом `-2`, `-3`… при занятом имени, Fix PR в `main` через `gh api`. Описание — шаблон `fix_pr.py`: `Fixes #N` или цитата Bug Report, причина, изменение, Reproduced/Unreproduced (до тикета 06 всегда Unreproduced), код сборки, пометка агента. Сбой публикации — «агент сдался» с причиной.
- Узел `cleanup` в конце любого маршрута удаляет рабочую копию (только `bug-investigator-*` во временной папке). Если процесс завершится на паузе, папка останется.
- Тесты: переходы пауз и шаблон Fix PR — на графе с `FakeStages`; разбор ссылки на issue. Git и `gh` тестами не покрыты (решено не строить моки внешних сервисов); push с суффиксом проверен разово на локальном bare-репозитории, чтение issue #2 — вживую.
- Сквозной прогон с реальным Fix PR и комментарием в issue ещё не делался.

**2026-11-22 — ревью.** Исправлено: CLI удаляет рабочую копию, если прогон оборвался до `cleanup` (исключение, Ctrl-C на паузе); `/dev/tty` открывается лениво, без терминала пауза = «Отклонить»; «Доработать» без комментария переспрашивает; комментарий человека Planner получает только в Plan сразу после доработки, не в повторах петли Critic; коммит агента без подписи и с запасной identity, если в git config нет имени или почты; ветка удаляется из remote, если PR не создан; заголовок Fix PR при пустом тексте; `--file` с несуществующим файлом — сообщение, а не traceback.

# 03 — Baseline и все Verdict

Status: ready-for-agent
Blocked by: 01, 02

## Готово, когда

- [ ] Узел Baseline перед Analyst; упавшие тесты передаются Analyst
- [ ] Verdict: Подтверждено / Не баг / Недостаточно данных / Заблокировано, с переходами по спецификации
- [ ] Для «Заблокировано» граф ищет открытые issue по именам упавших тестов и исключений (до 5), Analyst указывает связанное
- [ ] Комментарии в issue для «Недостаточно данных» и «Заблокировано» (для «Не баг» — в 04, после паузы)
- [ ] Критерии каждого Verdict в промпте Analyst (сейчас в промпте нет «Заблокировано»): «Подтверждено» — только если найдено место, объясняющее конкретное наблюдаемое поведение из Bug Report; нет симптома (ошибки, неверного результата, упавшего теста) — «Недостаточно данных», а не «Не баг»; для настроек сборки проверять унаследованное (parent POM и т. п.)
- [ ] Docker недоступен или Baseline не запустился — «агент сдался» сразу, до первого вызова модели (сейчас это выясняется только на Executor, после Coder)
